# Ricardo Oliveros-Ramos

**Quantitative Marine Ecologist • Ecosystem Modeller • Open-Source Scientific Software • Data Science**

I develop mathematical, statistical and computational methods for the **calibration, validation and application of complex ecosystem models** supporting **climate-ready fisheries management**.

My research integrates ecosystem modelling, stock assessment, ecological statistics and open-source scientific software to improve the scientific credibility of ecosystem models used for marine science and fisheries management.

I am one of the **developers of the [OSMOSE ecosystem modelling framework](https://github.com/osmose-model)**, contributor to **[FishMIP](https://github.com/Fish-MIP)** and **Chairperson of the Scientific Committee of [SPRFMO](https://github.com/SPRFMO)**.

🌐 **Website:** https://roliveros-ramos.github.io/
